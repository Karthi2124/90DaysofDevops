# Day 39 – What is CI/CD?

## My Learning

Today, I started learning about CI/CD and why it is important in DevOps.

I learned that CI/CD helps developers automate the process of testing, building, and deploying applications.

## What I Learned

### Continuous Integration (CI)

Continuous Integration means developers frequently push their code changes to a shared repository. The code is automatically tested to find problems early.

### Continuous Delivery

Continuous Delivery means the application is tested, built, and kept ready for deployment.

### Continuous Deployment

Continuous Deployment means that after all tests are successful, the application can automatically be deployed.

## Simple CI/CD Flow

```text
Developer
    ↓
Push Code to GitHub
    ↓
Test
    ↓
Build
    ↓
Deploy
```

## My Understanding

CI/CD helps reduce manual work and human errors. It makes the software development and deployment process faster and more reliable.
